# Logistis-GPT

**Logistis-GPT** is an AI agent for Greek accounting and tax workflows. It helps accountants, businesses, and developers understand and automate processes related to Greek taxation, bookkeeping, VAT, myDATA, invoicing, and regulatory compliance.
